# Crowdfunding Backend - Sprint 1

Backend desarrollado en **Spring Boot** conectado a **Supabase (PostgreSQL)**.

## Prerrequisitos

* Java 17 o superior.
* Maven o Gradle.

## Variables de Entorno Requeridas

Configura estas variables en tu entorno local antes de ejecutar la aplicación:

* `DB_URL`
* `DB_USER`
* `DB_PASSWORD`
